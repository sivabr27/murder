# FIRST Sight prototype (FAME 6.0, Problem Statement 1)

Concept prototype of a risk-tiered digital collateral assessment layer for Loan Against Property.
Open index.html in a browser. Six stages (intake, property passport, cross-check and tier, video inspection, valuer co-pilot, collateral card) on four demo cases.
Cases 1-3 are rebuilt from the anonymised sample reports in the case pack; case 4 is synthetic. Registry, map and comparable data are mocked. Not an IDFC FIRST Bank system.
