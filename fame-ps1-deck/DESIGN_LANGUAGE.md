# Design language, taken from the Grant Thornton CASEino reference deck

The reference deck has 21 pages: a cover, 14 content slides, an appendix divider, 3 appendix pages, a live-demo page and a thank-you page.
This file records the rules behind it so they can be applied to the FIRST Sight deck in IDFC colours.

## 1. The deck argues as a pyramid

- **Slide 1 (executive summary) is the whole deck on one page.** It holds:
    - a crisis / strategy / outcome triad;
    - the four crisis numbers;
    - a blueprint of the 5 pillars, the JV and the products;
    - the three phases;
    - the financial change as before → after pills;
    - seven milestone gates;
    - three advantages no competitor can copy.

  Each block on slide 1 is opened out by a later slide.
- **Slides 2 to 6 cover one pillar each, all on the same template**, so the reader learns the layout once and then reads every pillar quickly.
- **Slide 7 is the "it adds up" slide.** It shows how the pillars fund each other (a chain), a table of pillar → action → financial impact → strategic impact, what Phase 1 delivers and what that enables in Phase 2, and a combined before-vs-after table.
- **The closing slides cover the numbers, the master roadmap and governance.**
    - Combined financials, with scenarios and an assumptions table.
    - A master roadmap: workstreams by phase, gates, and a KPI scorecard showing the start, the midpoint and the target.
    - Governance: who owns what, the KPI for each owner, the trigger that makes the board step in, and a risk register.
- **The appendix holds the evidence:**
    - the benchmarks and evidence base, plus an assumptions register rated by sensitivity;
    - detailed financials;
    - references;
    - the live prototype demo, shown as phone mock-ups with a link. The prototype lives in the appendix, not in the main story.

## 2. Each pillar slide uses the same fixed template

| Zone | Content |
|---|---|
| Title band | A title in capitals that names the topic and its headline number (for example "PILLAR 1: UNLOCKING ₹600 CR TRAPPED INVENTORY"), then an italic **Objective** line: one sentence giving the plan, its numbers, its time frame and its constraint ("...within 90 days - without any domestic price cuts") |
| Top-left triad | THE PROBLEM (red number) · WHY THIS APPROACH (purple number) · EXPECTED OUTCOMES (green number). Each has one icon, one big number and one line of proof. This is the slide's argument in three seconds |
| Left body | The mechanism, split into named parts (5 channels, 4 tracks, 3 layers, 3 components, 5 tracks). Each part has a name, a timing tag, specifics, and **a pill with its own quantified result** |
| Left foot | The evidence: a scenario analysis (best / base / worst, each with a probability), an alternatives comparison (crossed-out options vs a ticked one), or a precedent callout (Dixon → Padget) |
| Right column, in this order | OPERATIONAL TIMELINE (4 month buckets, milestone flags with ✓, an outcome line such as "Month 12: …") → KEY RISKS & MITIGATIONS (2×2 cards: risk, gauge meter, mitigation with a green tick) → KPIs & STRATEGIC IMPACT (success-KPI icon tiles, plus WHY THIS MATTERS: 3 big numbers, each with a colour bar and a so-what) |
| Gold strip at the bottom | One sentence of transformation: **before → after + qualifier** ("₹600 Cr stranded inventory → ₹724-784 Cr real cash in 90 days (without a single domestic price cut)") |

## 3. Grammar at box level

- **A box title is a claim, not a label.** The pattern is "[COUNT] [THING] - [CLAIM]", for example "THE CRISIS - FOUR NUMBERS THAT DEMAND ACTION", "SEVEN MILESTONE GATES - PROOF AT EVERY STAGE", "WHY A JV - AND NOT THE ALTERNATIVES" or "THREE ADVANTAGES NO COMPETITOR CAN REPLICATE".
- **Every box ends with an italic line that states its conclusion.** Examples:
    - "Phase 1 funds Phase 2, Phase 2 proves Phase 3 | No phase can be skipped"
    - "Miss a gate and the board reviews"
    - "No new facilities. No new land. No new licences."

  This line states the box's conclusion. It never describes how to read the box.
- **Lines are short fragments anchored on numbers,** joined with `|` and `→`. Before → after is the default way to show a number ("Principal ₹1,200 Cr → ₹1,056 Cr"). Almost every line carries a number, a month or a named source.
- **Every part of the mechanism ends in money, time or volume.** No part is left unquantified.
- **Colour carries meaning:** red is the problem or today, green is the outcome or target, the brand colour is the approach, and gold is the takeaway. Before/after pills run pink → green.

## 4. Infographics the reference uses, and where each fits

| Infographic | Used for |
|---|---|
| Icon + big number triad | Problem / approach / outcome |
| Numbered component rows with result pills | The mechanism |
| Chevron timeline in 4 buckets, with flags and ✓ | Operational timeline |
| Gauge meters on 2×2 risk cards | Risk severity |
| KPI icon tiles + "Why this matters" bars | Impact |
| Before → after pill pairs | Any change in a metric |
| Diamond milestones on a line | Gates |
| Swimlane chevrons (streams × phases) | Master roadmap |
| Bullet bars with a diamond marker (start, now, target) | KPI scorecard |
| Comparison table with the winning column highlighted | Build vs buy |
| Crossed-out vs ticked option cards | Why not the alternatives |
| 3 scenario cards with probabilities | Sensitivity |
| Hub-and-spoke / org tree | Ownership and structure |
| Numbered S-curve path (1-5) | A user's journey |
| Chain of pillars with arrows | How the parts feed each other |
| Stacked bars, dual-axis line, donut | Financials and mix |
| Phone mock-ups | Prototype demo (appendix) |

From the reference sheet of 48 infographics, these are additionally useful: hexagon steps, a staircase, a target, a pyramid, layered stacks, a snake path, a cycle/flower, a funnel and percentage columns.

## 5. Where the last FIRST Sight deck missed the language

1. Every slide used a different layout, so the reader had to relearn the page each time. The reference repeats one template.
2. Box titles were labels ("RISK HEAT MAP", "WHY THE GAP EXISTS") rather than claims carrying numbers.
3. The italic lines described the box ("Each card shows…") instead of stating its conclusion.
4. Content ran as sentences; few rows had a before → after pair or a result pill.
5. The standard right column (timeline → risks with gauges → KPIs + why this matters) was not used consistently.
6. There was no "it all adds up" slide, no evidence register, and no prototype demo in the appendix.
7. The gold strips did not consistently state a before → after transformation.
